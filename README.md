# nicolapiperis-plugins

Nicola Piperis's Claude Code plugins.

| Plugin | What it does |
|---|---|
| [`mise-en-place`](plugins/mise-en-place/README.md) | A guided, human-in-the-loop development workflow backed by a personal knowledge base, the pantry: every ticket from the grill to the bill. |

## Install

```
/plugin marketplace add NicolaPiperis/plugins
/plugin install <plugin>@nicolapiperis-plugins
```
